## 一、呢個網頁係乜嘢？

**政策島（Policy Islands）** 係一個用嚟「睇清楚政策點樣協作」嘅互動 3D 可視化世界。佢唔係一隻遊戲、亦唔係一份靜態報告——佢係一個**決策支援工具**（decision-support tool），將複雜嘅政策關係變成一個可以行入去、望住、撳吓嘅城市。

核心比喻：**政策就係島、細項就係建築、協作就係橋**。

- 每座「島」= 一個政策範疇（交通、教育、醫療、房屋、環境、經濟）
- 島上面每座「建築」= 一個具體政策細項（巴士總站、社區診所、屋邨配額…）
- 島與島之間嘅「橋／協作線」= 政策之間嘅實際依賴關係
- 喺路上行嘅「小人」= 正在執行政策協作嘅市民／公務員（例如：搬緊「校車路線圖」由交通島送去教育島）

一句講晒：**「如果交通島改路線，邊幾條線會斷？」「邊個政策冇人接手？」「邊啲細項冇被引用？」——呢個世界一望就知。**

## 三、視覺與體驗特色

### 1. 香港主題建築（14 種港式原型 + 6 地標）

- 唐樓、公屋、商廈、叮叮車廠、天星碼頭、文武廟書齋、茶餐廳、街市、當鋪、舊戲院、賽馬會、麻雀館、舊火車站、燈塔
- 島嶼周邊有路燈、盆栽、灌木、花、串燈、長椅、大樹（櫻花／柳樹／果樹／棕櫚）

### 2. 日夜循環 + 天氣感

- 時鐘由 10:00 開始自動行（每秒 10 分鐘），HUD 四個按鈕直接跳：**清晨 06／白天 12／黃昏 18／夜晚 21**
- 夜晚：窗燈、路燈、島緣串燈全部發光（暖橙 #ffc777），海面有倒影感
- 夕陽、雲層、海面波浪時時變化

### 3. 流動協作線（Tube shader）

- 珊瑚色管狀線沿路網流動，代表「政策正在搬運」
- 官方實線／主題虛線／規劃點線，一眼可辨

### 4. 性能工程

- **InstancedMesh 零件庫**：10 種 instanced kind、1100+ instance、~90 draw calls
- **LOD 小物件管理**：502+ 個小物件（盆栽／花／長椅）距離 ≥26 自動隱藏，走近還原
- 自動降級：連續低幀率 → 關陰影＋降 pixel ratio
- `?q=low` 低畫質模式（舊手機／冇 GPU）、`?still=1` 凍結動畫
- CDN fallback：jsDelivr 失效自動切 unpkg（`?cdn=fallback`）

### 5. 雙語介面

- 預設繁體中文，`?lang=en` 全英文（data-en 屬性＋tr() 函式）
- 所有 UI、卡片、名牌、標籤同步翻譯

## 五、多人互動後端（Phase 2–4：真正嘅「活世界」）

前端係靚嘅，但令佢「活」嘅係後端：**Cloudflare Worker + Durable Object + SQLite**。

### 身份與安全
- **匿名 session**：每個瀏覽者自動攞一個 token（localStorage 記住）
- **限流**：每個 token 每分鐘最多 5 次 mutation（防 spam）
- **審計**：所有世界變更寫入 mutations log（seq 順序、actor 可追）

### 世界變更（mutation）功能
| 動作 | 效果 |
|---|---|
| ➕ 加建築 | 提交市民提案 → 集齊 5 票支持先正式落世界（Phase 5 提案制） |
| 🏷️ 認領新聞島 | 新聞島出現 3 日內可認領（+25 分） |
| 🙌 支持新聞島 | 支持度 ≥10 個 👍 島會變大 |
| 📰 新聞島生成 | 政府新聞公報／RTHK RSS 每 2 小時自動掃，主題分類 ~78% 覆蓋率 → 新島自動出現 |

### 即時同步
- WebSocket（DO）＋ **polling fallback**（12 秒一次，實測 100% 可靠）
- 任何用戶加嘢 → 全世界即時見到（item／island 自動 merge 入世界）

### 排行榜與分數
- 加建築 +10、提案通過 +20、認領新聞島 +25、投票 +1、完成每日任務 +15…
- 市民貢獻榜（🏆 按鈕）顯示 top 10

## 六、遊戲化設計（Phase 5：「政策」本身就係遊戲）

參考「遊戲化 × 政策教育」——政策嘅本質係「提案→審議→通過→落實」，所以我哋將成個流程做成遊戲機制：

### 1. 🗳️ 市民提案投票制
- 撳 ➕ → 揀島、揀建築、改名 → **變成 pending 提案**（唔係即時落世界）
- 其他市民喺面板度 👍／👎 投票
- **≥5 個支持票 → 正式落實**（建築出現、提案人 +20 分）
- 重複投票被拒、提案有審計紀錄
- 「呢個先係政策——要集齊民意先落實」

### 2. 🔮 政策影響 What-if 模擬
- 撳任何細項 → 一條「影響波」沿協作線擴散
- 顯示「改呢項 → 交通島 +8%、環境島 -20%」（方向按協作線權重推算）
- 受影響島同步變色（綠=正面、紅=負面）
- 決策者可以「如果改呢樣，邊度會受牽連？」一眼睇到

### 3. 📋 每日任務 + 成就徽章
- 「加一座建築／探訪 3 個新聞島／查看一條協作線／投票支持一個提案」
- 每日重置（香港時區）、完成 +15 分
- 進度條 live、完成自動送 server

### 4. 🏷️ 新聞島「認領 + 支持」
- 新聞島出現 → 可以認領（+25 分）／支持（+1 分）
- 支持度破 10 → 島 scale 變大（「民意膨脹」視覺化）
- 3 日後認領窗口關閉（把握時機！）

## 八、UX 進化（參考「生活黑客群島」學返嚟）

參考咗 Lifehacker 台灣嘅「生活黑客群島」（同類型：島嶼＝真實社群頻道、24 小時活動重播、導覽飛行），將佢嘅最強概念移植兼改良到政策島：

### 1. 🔥 島熱度 badge
- 每個島名牌顯示**活躍度數字**（如「04 房屋 7」）
- 活躍度 ≥4 自動 **hot 高亮**（珊瑚外圈＋數字脈動）
- 邊個島最多協作／最多事件，一眼睇到

### 2. 📜 事件重播（24 小時城市日記）
- 底部黑色 pill：**每 2.8 秒**彈一件城市事件
- 「🚌 校車路線圖更新，交通島 → 教育島」
- 「💰 稅收影響估算，經濟島完成季度報告」
- 事件出現時該島 label 閃珊瑚色光環
- 靜態版都有 seed 示範事件，唔會空

### 3. 🏛️ 市長導覽（有劇本飛行）
- 「🏛️ 導覽」按鈕 → **9 步敘事導覽**：
  1. 歡迎（全景）→ 2-7 六座主題島逐個飛（講幾多細項、幾多協作線）→ 8 新聞島 → 9 總結
- 導覽期間自動暫停世界動畫，完成還原

### 4. 📱 手機 UX 改進
- **viewOffset**：手機開卡片時鏡頭自動向上推，島唔會被 sheet 遮住
- **名牌 priority**：遠鏡時熱島+選中優先，其他淡化讓位

## 十、呢個網頁可以達成嘅目標

### 1. 政策教育（最重要）
- 公民／學生／公務員可以喺一個直覺嘅 3D 世界入面，理解「交通政策唔係淨係巴士站」——佢連住教育（校車）、醫療（送診）、經濟（營商）
- **政策視覺化令抽象嘢具體**：唔使讀 200 頁文件，行入個城市就明

### 2. 決策支援（decision-support）
- What-if 模擬：「如果改咗屋邨配額，邊啲島會被牽連？」
- 協作線一睇就知「邊條政策連住最多人」→ 邊個係關鍵節點
- 熱度 badge：邊個政策範疇最活躍／最多人參與

### 3. 公民參與平台
- 市民可以**提案加建築**（提政策）、**投票**（參與審議）、**認領新聞島**（追蹤議題）
- 排行榜令參與「有得睇、有得比」
- 呢個係「政策民主」嘅微型示範：提案 → 民意 → 落實

### 4. 新聞驅動嘅「活」城市
- 政府新聞／RTHK RSS 每 2 小時掃一次 → 新議題自動變成島
- 城市反映「現實世界發生緊乜嘢」——唔係死資料

### 5. 展示／Demo
- 一個令人「嘩」嘅互動作品：香港建築、日夜、小人、3D 城市
- 適合公開展示、研討會、學校工作坊（?q=low 連舊機都跑到）
